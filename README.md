# Лабораторная работа 7. Многоальтернативная обработка

## Описание файлов работы

В данной работе представлены решения задач на использование оператора многоальтернативного выбора (`switch`) в языке C.

### 1. `1.c` — Распознавание символов (Задача 1)
Программа определяет категорию введенного пользователем символа с использованием оператора `switch`:
- **Категории символов:**
  - Цифры (`'0'` ... `'9'`) $\to$ выводится `"это цифра"`
  - Латинские буквы строчные (`'a'` ... `'z'`) и прописные (`'A'` ... `'Z'`) $\to$ выводится `"это буква"`
  - Любые другие символы $\to$ выводится `"неизвестный символ"`
- **Особенности реализации:**
  - Группировка меток `case` («проваливание» без `break` внутри одной группы символов).
  - Безопасное чтение символа с пропуском пробельных символов через `scanf(" %c", &c)`.
- **Примеры работы:**
  - Ввод `5` $\to$ `это цифра`
  - Ввод `w` $\to$ `это буква`
  - Ввод `G` $\to$ `это буква`
  - Ввод `?` $\to$ `неизвестный символ`

### 2. `2.c` — Калькулятор (Задача 2)
Программа реализует простой калькулятор для вычисления арифметических выражений, вводимых в одну строку вида `<число1><операция><число2>`:
- **Поддерживаемые операции:**
  - `+` — сложение (`x + y`)
  - `-` — вычитание (`x - y`)
  - `*` — умножение (`x * y`)
  - `/` — деление (`x / y`) с проверкой деления на ноль (`y == 0.0f`)
  - `^` — возведение в степень (`powf(x, y)`) как дополнительный функционал
- **Особенности реализации:**
  - Ввод осуществляется функцией `scanf("%f %c %f", &x, &c, &y)`, что позволяет вводить выражение как слитно (`2.5+3.5`), так и через пробелы (`2.5 + 3.5`).
  - Вычисление и вывод результата производятся непосредственно внутри функции `printf`:
    ```c
    printf("=%f\n", x + y);
    ```
  - Использование `setlocale(LC_NUMERIC, "C")` гарантирует корректный ввод вещественных чисел с точкой в качестве разделителя.
- **Примеры работы:**
  - Ввод `2.5+3.5` $\to$ `=6.000000`
  - Ввод `10 - 4` $\to$ `=6.000000`
  - Ввод `3 * 7` $\to$ `=21.000000`
  - Ввод `7 / 2` $\to$ `=3.500000`
  - Ввод `2 ^ 3` $\to$ `=8.000000`
  - Ввод `5 / 0` $\to$ `Ошибка: деление на ноль!`

### 3. `3.c` — Дни недели и расстояние до воскресенья (Задача 3, Вариант 21)
Программа по порядковому номеру дня недели (от 1 до 7) определяет его название и выводит количество дней, оставшихся до воскресенья:
- По условию задания многоальтернативный выбор реализован с помощью оператора `switch` без использования конструкции `if-else`.
- **Соответствие номеров и результатов:**
  | Номер | День недели | Сообщение |
  | :---: | :--- | :--- |
  | 1 | Понедельник | `Понедельник. До воскресенья осталось 6 дней.` |
  | 2 | Вторник | `Вторник. До воскресенья осталось 5 дней.` |
  | 3 | Среда | `Среда. До воскресенья осталось 4 дня.` |
  | 4 | Четверг | `Четверг. До воскресенья осталось 3 дня.` |
  | 5 | Пятница | `Пятница. До воскресенья осталось 2 дня.` |
  | 6 | Суббота | `Суббота. До воскресенья остался 1 день.` |
  | 7 | Воскресенье | `Воскресенье. Сегодня воскресенье (0 дней).` |
- При вводе числа вне диапазона $1..7$ срабатывает ветка `default` с выводом сообщения об ошибке.
